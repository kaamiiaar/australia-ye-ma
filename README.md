# Australia-ye Ma prototype

A dependency-free, mobile-first product prototype for local testing.

## Run locally

```bash
python3 -m http.server 4173
```

Then open [http://localhost:4173](http://localhost:4173).

## Files

- `VISION.md` — product purpose, scope, trust model, and long-term direction.
- `TECHNICAL_PLAN.md` — recommended production architecture and delivery phases.
- `AGENTS.md` — working rules for coding agents in this repository.
- `index.html`, `styles.css`, `app.js` — the local interactive prototype.

All content in the prototype is representative mock data, not a live directory.
